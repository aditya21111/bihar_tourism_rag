OVERVIEW:
J.P. Ganga Path, also known as Ganga Pathway, is a scenic 20.5-kilometre-long expressway built along the Ganga river in Patna, Bihar. Connecting Digha to Deedarganj, it features both at-grade and elevated sections, offering a smooth drive with panoramic views of the river. The first phase up to PMCH is currently open to traffic, with future extensions planned. 

DETAILED DESCRIPTION:
J.P. Ganga Path is a major infrastructure and scenic road project in Patna, running along the river Ganges. It spans 20.5 kilometres between Digha and Deedarganj. The road consists of a 6.5 Kms at-grade level section and a 14 Kms elevated section. It connects Digha to Kacchi Dargah along the river. The first phase up to PMCH has been opened for traffic. The second phase of the expressway is planned to extend by 18 Kms up to Fatuah.
